# Assignments

Here you will be able to find the CompSys assignments

## Report
Remember that all members and their KU-id must be included on the first page of the report.

## Source code
Only submit a zip-file called src.zip, containing source code, tests, Makefile, etc. Do not include the programs that you build; run "make clean" before compressing.

Do not include overly large files, such as very large test files. 

## Submission instructions
This is intended as an assignment for 2-3 people.

If you need help finding a group please use the 'studygroup-tinder' channel on the discord, or talk with your TA.

## Submission updates
If you update any part of you submission, you must submit everything again; both report and zip-file. We will only consider the final submission that you make.

## AI Declaration
All submissions must include a Declaration of Academic Use of AI.
